## 🎯 Наша миссия

> **Современные игровые движки стали слишком сложными и тяжелыми.** 
> Цель **Unreal Typewriter** — убрать все барьеры для новичков. Это легкая, полностью браузерная среда, где каждый может запустить редактор в один клик, понять логику 3D-пространства и сразу начать писать свои первые игры.

Проект написан на **чистом JavaScript (Vanilla JS)** без использования тяжелых сторонних фреймворков и библиотек (вроде Three.js). Это делает его идеальным «живым учебником» по устройству 3D-графики, математики матриц и WebGL изнутри.

---

## ✨ Ключевые особенности

* 🚀 **Мгновенный старт** — Работает прямо в браузере, не требует скачивания гигабайт софта и настройки окружения.
* 🧊 **Знакомый UI/UX** — Интерфейс панелей (*Viewport, World Outliner, Details, Content Browser*) повторяет логику профессиональных движков (Unreal Engine, Unity).
* 📦 **Управление проектами** — Полноценный импорт и экспорт файлов проектов (`.utproj`) и кастомных ассетов моделей (`.type`).
* 🎮 **Готовые шаблоны** — Встроенный интерактивный пресет **Zombie Shooter (3D)** для быстрого изучения коллизий и логики сцены.
* 🌐 **Экспорт в Web** — Возможность скомпилировать и сохранить готовую игру в один HTML-файл для мгновенной публикации.
* 🛠️ **Встроенный моделлер** — Инструменты для базовой манипуляции с сеткой (mesh) объектов прямо внутри редактора.

| Компонент | Технология | Описание |
